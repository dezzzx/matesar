# Factorización de polinomios

## Sacar factor común
  ax + ay = a(x+y)

## Identidades notables
  (a+b)² = a² + 2ab + b²
  (a-b)² = a² - 2ab + b²
  (a+b)(a-b) = a² - b²
  (a+b)³ = a³ + 3a²b + 3ab² + b³
  a³ + b³ = (a+b)(a²-ab+b²)
  a³ - b³ = (a-b)(a²+ab+b²)

## Trinomio de 2º grado
  ax² + bx + c = a(x - x1)(x - x2)
  donde x1, x2 son las raíces (fórmula general)

## Agrupación de términos
  ax + ay + bx + by = a(x+y) + b(x+y) = (x+y)(a+b)
