# Reglas de derivación

  (f ± g)'  = f' ± g'
  (k·f)'    = k·f'                        (k constante)
  (f·g)'    = f'·g + f·g'
  (f/g)'    = (f'·g - f·g') / g²
  (f^n)'    = n·f^(n-1)·f'                (regla de la potencia + cadena)
  (√f)'     = f' / (2√f)
  (e^f)'    = f'·e^f
  (ln f)'   = f'/f
  (a^f)'    = f'·a^f·ln(a)
  (sen f)'  = f'·cos(f)
  (cos f)'  = -f'·sen(f)
  (tg f)'   = f'·(1+tg²(f))

## Derivadas de orden superior
  f''(x) = derivada de f'(x)
  f'''(x), f⁽ⁿ⁾(x)... derivar sucesivamente
