# Tabla de derivadas

  d/dx [k]         = 0                    (k constante)
  d/dx [x^n]       = n·x^(n-1)
  d/dx [√x]        = 1/(2√x)
  d/dx [1/x]       = -1/x²
  d/dx [e^x]       = e^x
  d/dx [a^x]       = a^x · ln(a)
  d/dx [ln(x)]     = 1/x
  d/dx [log_a(x)]  = 1/(x·ln(a))
  d/dx [sen(x)]    = cos(x)
  d/dx [cos(x)]    = -sen(x)
  d/dx [tg(x)]     = 1 + tg²(x) = sec²(x) = 1/cos²(x)
  d/dx [cotg(x)]   = -1/sen²(x)
  d/dx [arcsen(x)] = 1/√(1-x²)
  d/dx [arccos(x)] = -1/√(1-x²)
  d/dx [arctg(x)]  = 1/(1+x²)

  (Todas se combinan con la regla de la cadena cuando el argumento es
  una función u(x) en vez de x, ver regla_cadena.md)
