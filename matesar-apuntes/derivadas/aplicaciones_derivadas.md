# Aplicaciones de la derivada

## Recta tangente en x = a
  y - f(a) = f'(a)·(x - a)

## Recta normal en x = a
  y - f(a) = (-1/f'(a))·(x - a)     (pendiente perpendicular)

## Monotonía (crecimiento / decrecimiento)
  f'(x) > 0  →  f creciente
  f'(x) < 0  →  f decreciente
  f'(x) = 0  →  posible extremo relativo (máximo o mínimo)

## Extremos relativos (criterio de la 2ª derivada)
  Si f'(a) = 0:
    f''(a) > 0  →  mínimo relativo en a
    f''(a) < 0  →  máximo relativo en a
    f''(a) = 0  →  no concluyente (probar con la 1ª derivada / signo)

## Curvatura (concavidad)
  f''(x) > 0  →  cóncava hacia arriba (∪, "sonrisa")
  f''(x) < 0  →  cóncava hacia abajo (∩)
  f''(x) = 0 y cambia de signo → punto de inflexión

## Optimización (problemas de máximos/mínimos)
1. Plantear la función a optimizar en función de una sola variable
   (usar restricciones para eliminar variables).
2. Derivar e igualar a 0.
3. Comprobar que es máximo/mínimo (2ª derivada o estudio de signo).
4. Comprobar que la solución tiene sentido en el contexto del problema.
