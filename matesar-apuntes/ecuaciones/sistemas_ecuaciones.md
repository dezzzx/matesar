# Sistemas de ecuaciones

## Métodos de resolución (sistemas lineales)
- Sustitución: despejar una incógnita en una ecuación y sustituir en la otra.
- Igualación: despejar la misma incógnita en ambas y igualar.
- Reducción: sumar/restar ecuaciones (multiplicadas si hace falta) para
  eliminar una incógnita.
- Método de Gauss (para 3x3): triangular la matriz ampliada.

## Clasificación según el número de soluciones
- Sistema Compatible Determinado (SCD): una única solución
- Sistema Compatible Indeterminado (SCI): infinitas soluciones
- Sistema Incompatible (SI): sin solución

## Sistemas no lineales (uno lineal + uno cuadrático)
  Despejar en la ecuación lineal y sustituir en la de 2º grado.

## Regla de Cramer (2x2)
  ax + by = c
  dx + ey = f

  x = (ce - bf) / (ae - bd)
  y = (af - cd) / (ae - bd)
