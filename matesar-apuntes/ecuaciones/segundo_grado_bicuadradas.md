# Ecuaciones de 2º grado, bicuadradas e irracionales

## Ecuación de 2º grado: ax² + bx + c = 0
  x = (-b ± √(b²-4ac)) / (2a)

  Discriminante Δ = b² - 4ac
  Δ > 0 → dos soluciones reales distintas
  Δ = 0 → una solución doble
  Δ < 0 → no hay soluciones reales (dos complejas)

  Suma y producto de raíces:
  x1 + x2 = -b/a
  x1 · x2 = c/a

## Ecuaciones bicuadradas: ax⁴ + bx² + c = 0
  Cambio de variable: t = x²  →  a·t² + b·t + c = 0
  Resolver en t, y luego x = ±√t  (descartar t < 0)

## Ecuaciones con valor absoluto
  |f(x)| = k  (k>0)  →  f(x) = k  ó  f(x) = -k
  |f(x)| = |g(x)|    →  f(x) = g(x)  ó  f(x) = -g(x)
