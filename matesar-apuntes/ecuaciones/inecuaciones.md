# Inecuaciones

## Inecuaciones de 1er grado
  Igual que una ecuación, pero: si se multiplica o divide por un número
  NEGATIVO, se invierte el sentido de la desigualdad.

## Inecuaciones de 2º grado: ax² + bx + c > 0 (o <, ≥, ≤)
1. Resolver la ecuación ax² + bx + c = 0 → obtener las raíces.
2. Las raíces dividen la recta real en intervalos.
3. Estudiar el signo del polinomio en cada intervalo (probando un valor).
4. Seleccionar los intervalos que cumplen la desigualdad.

## Inecuaciones racionales: P(x)/Q(x) > 0
1. Hallar las raíces del numerador y del denominador (Q(x) ≠ 0 siempre).
2. Estudiar el signo en cada intervalo como arriba.

## Notación de intervalos
  (a, b)  → a < x < b        [a, b] → a ≤ x ≤ b
  (-∞, a) → x < a            [a, +∞) → x ≥ a
