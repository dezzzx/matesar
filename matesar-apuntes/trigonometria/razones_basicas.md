# Razones trigonométricas básicas

  sen(α) = cateto opuesto / hipotenusa
  cos(α) = cateto contiguo / hipotenusa
  tg(α)  = cateto opuesto / cateto contiguo = sen(α)/cos(α)

  cosec(α) = 1/sen(α)
  sec(α)   = 1/cos(α)
  cotg(α)  = 1/tg(α) = cos(α)/sen(α)

## Ángulos notables
  ángulo:  0°   30°      45°      60°      90°
  sen:     0    1/2      √2/2     √3/2     1
  cos:     1    √3/2     √2/2     1/2      0
  tg:      0    √3/3     1        √3       ∄

## Signos por cuadrante
  I:  sen +, cos +, tg +
  II: sen +, cos -, tg -
  III:sen -, cos -, tg +
  IV: sen -, cos +, tg -
