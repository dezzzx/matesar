# Ecuaciones trigonométricas

## Soluciones generales (ángulo en radianes, k ∈ ℤ)
  sen(x) = sen(a)  →  x = a + 2kπ   ó   x = π - a + 2kπ
  cos(x) = cos(a)  →  x = a + 2kπ   ó   x = -a + 2kπ
  tg(x)  = tg(a)   →  x = a + kπ

## Estrategia general
1. Usar identidades para dejar una sola razón trigonométrica.
2. Si aparece sen²+cos² mezclado, usar sen²(x)=1-cos²(x) (o viceversa)
   y hacer cambio de variable t = sen(x) o t = cos(x).
3. Resolver la ecuación algebraica en t.
4. Deshacer el cambio y dar todas las soluciones dentro del intervalo pedido
   (normalmente [0, 2π) o [0°, 360°)).
