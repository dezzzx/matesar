# Logaritmos: definición y propiedades

## Definición
  log_a(x) = y   ⟺   a^y = x     (a > 0, a ≠ 1, x > 0)

  ln(x) = log_e(x)      (logaritmo neperiano, e ≈ 2.71828)
  log(x) = log_10(x)    (logaritmo decimal)

## Propiedades fundamentales
- log_a(1) = 0
- log_a(a) = 1
- log_a(x·y) = log_a(x) + log_a(y)
- log_a(x/y) = log_a(x) - log_a(y)
- log_a(x^n) = n·log_a(x)
- log_a( n√x ) = (1/n)·log_a(x)
- a^(log_a(x)) = x
- log_a(x) no existe si x ≤ 0
