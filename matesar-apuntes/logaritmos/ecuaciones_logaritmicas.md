# Ecuaciones logarítmicas y exponenciales

## Ecuaciones exponenciales
- Si a^f(x) = a^g(x)  →  f(x) = g(x)  (misma base)
- Si no se puede igualar la base: aplicar logaritmos a ambos lados
  a^x = b   →   x = log_a(b) = ln(b)/ln(a)
- Cambio de variable típico: a^(2x) = (a^x)²  →  llamar t = a^x

## Ecuaciones logarítmicas
1. Aplicar propiedades para dejar un único logaritmo en cada lado.
2. Si log_a(f(x)) = log_a(g(x))  →  f(x) = g(x)
3. Si log_a(f(x)) = k  →  f(x) = a^k
4. **Comprobar el dominio**: el argumento del logaritmo debe ser > 0
   (pueden salir soluciones que no valen)

## Ejemplo
  log(x) + log(x-3) = 1
  log(x(x-3)) = 1
  x(x-3) = 10
  x² - 3x - 10 = 0  →  x = 5  ó  x = -2
  Comprobación dominio: x > 3 necesario → solo vale x = 5
