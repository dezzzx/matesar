# Tipos de funciones y sus gráficas

## Lineal / afín: f(x) = mx + n
  Recta. m = pendiente, n = ordenada en el origen.

## Cuadrática: f(x) = ax² + bx + c
  Parábola. Vértice en x = -b/(2a).
  a > 0 → abre hacia arriba (mínimo); a < 0 → abre hacia abajo (máximo)

## Función a trozos
  Definida con distintas expresiones según el intervalo de x.

## Exponencial: f(x) = a^x  (a > 0, a≠1)
  a > 1 → creciente;  0 < a < 1 → decreciente
  Dominio ℝ, Recorrido (0, +∞), asíntota horizontal y=0

## Logarítmica: f(x) = log_a(x)
  Inversa de la exponencial. Dominio (0,+∞), asíntota vertical x=0

## Valor absoluto: f(x) = |x|
  f(x) = x si x≥0;  f(x) = -x si x<0

## Racional: f(x) = 1/x
  Hipérbola, asíntotas en los ejes
