# Dominio de una función

## Polinómica: f(x) = polinomio
  Dominio = ℝ (todos los reales)

## Racional: f(x) = P(x)/Q(x)
  Dominio = ℝ - {x : Q(x) = 0}

## Raíz de índice par: f(x) = n√(g(x))  (n par)
  Dominio: g(x) ≥ 0

## Raíz de índice impar
  Dominio = ℝ

## Logarítmica: f(x) = log(g(x))
  Dominio: g(x) > 0

## Cociente con raíz en el denominador
  Combinar ambas condiciones (radicando ≥ 0 y ≠ 0 si es par)
