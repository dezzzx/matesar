# Propiedades de los radicales

- n√a = a^(1/n)
- n√a · n√b = n√(a·b)
- n√a / n√b = n√(a/b)   (b ≠ 0)
- (n√a)^m = n√(a^m) = a^(m/n)
- m√(n√a) = (m·n)√a          (raíz de raíz: se multiplican los índices)
- n√(a^n) = a   si n impar
- n√(a^n) = |a|  si n par

## Simplificar radicales
1. Descomponer el radicando en factores primos.
2. Sacar fuera los factores cuyo exponente sea ≥ índice.
3. Ejemplo: √72 = √(2^3·3^2) = √(2^2·2·3^2) = 2·3·√2 = 6√2

## Reducir a índice común
Para sumar/comparar radicales de distinto índice:
n√a  y  m√b  →  llevar ambos al mínimo común múltiplo de n y m,
usando  n√a = (n·k)√(a^k)
