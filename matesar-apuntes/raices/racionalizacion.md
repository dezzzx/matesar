# Racionalización de denominadores

## Caso 1: un solo radical (raíz cuadrada)
  a / √b   →   multiplicar por √b/√b
  a/√b = (a·√b)/b

## Caso 2: raíz de índice n
  a / n√(b^m)  →  multiplicar por  n√(b^(n-m)) / n√(b^(n-m))
  para completar el radicando hasta b^n

## Caso 3: binomio con raíz cuadrada (conjugado)
  a / (b + √c)  →  multiplicar por el conjugado (b - √c)
  (b+√c)(b-√c) = b² - c

  Ejemplo:
  3 / (2 + √5) = 3(2-√5) / (4-5) = 3(2-√5)/(-1) = -3(2-√5) = 3√5 - 6

## Caso 4: binomio con dos raíces
  1 / (√a + √b)  →  multiplicar por (√a - √b)
  (√a+√b)(√a-√b) = a - b
