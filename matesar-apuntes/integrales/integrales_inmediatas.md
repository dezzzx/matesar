# Integrales inmediatas

  ∫ x^n dx        = x^(n+1)/(n+1) + C     (n ≠ -1)
  ∫ 1/x dx        = ln|x| + C
  ∫ e^x dx        = e^x + C
  ∫ a^x dx        = a^x/ln(a) + C
  ∫ sen(x) dx     = -cos(x) + C
  ∫ cos(x) dx     = sen(x) + C
  ∫ sec²(x) dx    = tg(x) + C          [= ∫(1+tg²x)dx]
  ∫ 1/(1+x²) dx   = arctg(x) + C
  ∫ 1/√(1-x²) dx  = arcsen(x) + C
  ∫ k dx          = kx + C

## Propiedades
  ∫ [f(x) ± g(x)] dx = ∫f(x)dx ± ∫g(x)dx
  ∫ k·f(x) dx        = k·∫f(x)dx

## Con regla de la cadena "al revés" (cuasi-inmediatas)
  ∫ f'(x)·[f(x)]^n dx  = [f(x)]^(n+1)/(n+1) + C
  ∫ f'(x)/f(x) dx      = ln|f(x)| + C
  ∫ f'(x)·e^f(x) dx    = e^f(x) + C
  ∫ f'(x)·cos(f(x)) dx = sen(f(x)) + C
  ∫ f'(x)·sen(f(x)) dx = -cos(f(x)) + C
